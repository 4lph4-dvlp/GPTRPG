**`openai_provider.py`** — `OpenAIProvider`. `name = "openai"`. 생성자는 API 키와 선택적 기본 주소·추가 헤더를 받아 `openai.OpenAI(...)` 를 만든다. `list_models` 는 `self._client.models.list()` 를 순회해 `m.id` 목록을 정렬해 돌려준다. `complete` 는 `chat.completions.create` 를 부르고 응답의 `usage.prompt_tokens`/`usage.completion_tokens` 와 직접 잰 경과 시간으로 `AgentResult` 를 채운다. `stream` 은 `stream=True` 와 `stream_options={"include_usage": True}` 로 부르고 델타를 흘려보낸 뒤 마지막 usage 조각으로 `last_result()` 값을 채운다. OpenAI 계열의 프롬프트 캐싱에는 코드로 붙일 분기점이 없다 — 접두를 안정 순서로 유지하는 것이 유일한 지렛대라는 사실을 파일 도크스트링에 적는다(`prompt_assembly` 가 그 순서를 이미 강제한다).

**`nim_provider.py`** — `NimProvider`. `name = "nim"`. Nvidia NIM 은 OpenAI 호환 REST 표면이므로 `OpenAIProvider` 를 기본 주소 `https://integrate.api.nvidia.com/v1` 로 만들어 위임한다. 별도 SDK를 설치하지 않는다.

**`openrouter_provider.py`** — `OpenRouterProvider`. `name = "openrouter"`. 같은 방식으로 기본 주소 `https://openrouter.ai/api/v1` 를 쓴다. 조사 단계가 확인하지 못한 항목이 하나 있다 — 귀속 헤더가 필수인지 선택인지. 넣어서 손해 볼 것이 없으므로 `HTTP-Referer` 와 `X-Title` 을 생성 시점에 기본 헤더로 붙이고, 그 값은 이 도구를 가리키는 고정 문자열로 둔다. 이것이 조사 단계의 미해결 질문에 대한 방어적 선택임을 파일 도크스트링에 적는다.

**`gemini_provider.py`** — `GeminiProvider`. `name = "gemini"`. `google.genai` 클라이언트를 쓴다. `list_models` 는 클라이언트의 모델 목록을 순회해 이름을 돌려준다. `complete`/`stream` 은 generate-content 계열 호출을 쓰고, 토큰 수는 응답의 usage metadata 에서 읽어 `AgentResult` 의 `prompt_tokens`/`completion_tokens` 로 옮긴다. Gemini 계열의 암묵 캐싱은 기본으로 켜져 있고 같은 접두 규율로 적중하므로 `caches.create` 로 명시 캐시를 만드는 왕복을 이번 단계에 넣지 않는다 — 그 판단 근거를 파일 도크스트링에 적는다. 조사 단계에서 이 SDK 의 정확한 메서드·필드 이름은 문서 대조까지만 하고 실행 확인을 못 했으므로, 구현 전에 `python -c "import google.genai as g; help(g.Client)"` 로 실제 서명을 한 번 확인한 뒤 맞춘다.

**`providers/__init__.py`** — `PROVIDER_FACTORIES` 에 네 어댑터를 더해 다섯을 채운다. `get_provider` 는 그대로 두되, 어댑터가 전부 등록됐으므로 `ProviderNotImplemented` 갈래는 이제 도달하지 않는다는 사실을 주석으로 남기고 갈래 자체는 지우지 않는다(여섯 번째 제공자를 더할 때 다시 쓰인다). `base.py` 의 `Provider` 프로토콜에 `@runtime_checkable` 을 붙여 프로토콜 준수 시험이 가능하게 한다.

**`tests/test_providers.py`** — 네트워크를 타지 않는 시험만 쓴다. 다섯 어댑터 클래스를 가짜 키로 만들어 프로토콜 준수를 확인하고, `PROVIDER_FACTORIES` 와 `PROVIDER_ENV_VARS` 의 열쇠 집합이 같은지 확인하고, `get_provider` 의 세 예외 갈래를 확인하고(키 값이 예외 메시지에 없다는 것 포함), NIM 과 OpenRouter 인스턴스의 기본 주소가 서로 다른지 확인한다. SDK 클라이언트 생성이 네트워크를 타면 `monkeypatch` 로 생성자를 가로챈다.
