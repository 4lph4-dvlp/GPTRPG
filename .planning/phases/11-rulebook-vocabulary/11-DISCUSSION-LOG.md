## 그릇의 뼈대 — 축을 누가 선언하나

**Q1. 자원 축의 목록을 누가 가지고 있어야 합니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 룰북이 목록을 가진다 | 룰북이 먼저 적고 캐릭터는 값만 채운다. 「안 쓴다」를 적을 자리가 생긴다 | ✓ |
| 룰북이 기본을 정하고 캐릭터가 더할 수 있다 | 지금 데이터 모양이 살아남지만 「안 쓴다」 약속이 헐거워진다 | |
| 지금처럼 캐릭터가 알아서 갖는다 | 고칠 코드가 가장 적지만 축 목록을 알려면 캐릭터를 다 뒤져야 한다 | |

**사용자 답변:** 「1번을 기본으로 하되, 만약 사용자가 만든 룰북이 목록을 갖고 있지 않을 경우를 생각해야 한다」
**메모:** 이 단서가 곧바로 Q2를 만들었다.

**Q2. 자원 축 목록을 아예 안 적은 룰북이 들어오면?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 등록할 때 거부한다 | 「없다」고 말하려면 명시적으로 적어야 한다. 프로젝트의 기존 규율과 같다 | ✓ |
| 받아주되 「안 정함」으로 표시한다 | 제3의 상태로 남기고 등록 단계에서 드러낸다 | |
| 우리 것은 거부, 남의 것은 표시 | 두 경로로 갈리므로 규칙이 하나 늘어난다 | |

**Q3. 숫자가 아닌 자원(태그 목록·주사위 등급·이름 붙은 칸)을 어디에 담을까요?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 네 칸을 넓히는 것을 다시 논의한다 | 그릇을 하나로 유지하려면 결국 이 길. 잠금 결정의 적용 범위 재설정 | ✓ |
| 네 칸은 그대로 두고 옆에 새 그릇 | 잠금을 안 건드리지만 「하나의 그릇」이 사실상 둘이 된다 | |
| 이번에는 숫자형만 다룬다 | 가장 얼리지만 선언해도 안 돌아가는 상태가 한 단계 남는다 | |

**메모:** 논의 시작 시 이 충돌을 먼저 보고했다 — 잠긴 결정(「네 칸 그대로」)과 이번 단계 목표(형태를 룰북이 고른다)가 정면으로 부딪힌다는 것.

**Q4. 룰북이 선언하는 축 목록은 적·NPC에도 같이 적용됩니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 목록은 하나, 누가 뭘 갖는지는 개별 | 그릇이 진짜로 하나로 유지된다 | ✓ |
| 두 벌로 나누어 선언한다 | 경계는 분명하지만 같은 이름을 두 번 적게 된다 | |
| 캐릭터에만 강제하고 적은 자유롭게 | 적 데이터를 안 고쳐도 되지만 「안 쓴다」가 적 쪽에서 안 지켜진다 | |

## 「안 쓴다」를 어떻게 말하나

**Q1. 룰북이 「안 쓴다」를 적는 방식?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 개념마다 반드시 답하게 한다 | 빠뜨림이 구조적으로 불가능해진다 | ✓ |
| 「안 쓰는 것」을 한자리에 모아 적는다 | 읽기 쉽지만 양쪽 다 비면 여전히 새어나간다 | |
| 목록에 없으면 없는 것으로 본다 | 가장 간단하지만 이 단계의 성공 기준 3과 정면으로 부딪힌다 | |

**Q2. 나중에 새 개념이 생겼을 때 이미 있는 룰북은?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 룰북에 판 번호를 둔다 | 옛 판 룰북이 그대로 돌아가되 새 개념은 꺼진다 | |
| 그때 가면 룰북을 전부 고친다 | 지금 룰북이 둘뿐이라 싸다 | ✓ (사용자 지적으로 재구성) |
| 새 개념은 「기본은 안 씀」으로 | 고칠 것이 없지만 Q1의 약속이 새 개념 쪽에서 깨진다 | |

**사용자 답변:** 「게임 중에 룰북이 바뀌는 경우는 없잖아? 오리지널 TRPG에서도 기존 룰북으로 게임이 끝날 때까지 진행하니 새 개념이 생길 일이 없지 않나」
**메모:** 맞는 지적. 「새 개념」은 게임 시간의 문제가 아니라 우리가 다음 단계에서 어휘를 추가할 때 저장소 안 룰북 파일에 빈칸이 생기는 문제라고 정정해 설명했고, 그렇다면 판 번호 장치를 만들 이유가 없다는 결론에 도달했다. 다시 필요해지는 시점(남의 룰북 수용)만 기록에 남겼다.

**Q3. 「이 세계에 소지품이 없다」고 선언했을 때 AI 진행자는 그걸 알아야 합니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 「없다」고 명시적으로 알려준다 | 알려주지 않으면 AI가 없는 개념을 지어낸다 | |
| 아무것도 안 보내고 끝낸다 | 가장 가볍지만 지어내는 것을 막을 장치가 없다 | |
| 이번엔 화면·판정까지만 | 이번 단계가 작아진다 | |

**사용자 답변(자유 입력):** 「룰북에서는 소지품이 없을지언정, 자유로운 TRPG에서는 암묵적이고 허용 가능한 범위의 소지품이라는 개념이 있지 않을까? 예를 들어 퇴역한 전설의 기사를 찾아가 설득하는 서사에서 왕가에서 받은 기사의 증표를 보여주며 … 라는 서사를 만들기 위해 "기사의 증표"라는 소지품을 언급할 수 있는 거지. 이런 부분도 유연하게 처리할 수 있어야 하지 않을까?」
**메모:** 선택지 셋 전부를 무효로 만든 답이다. 「안 쓴다」가 한 갈래가 아니라 **「규칙으로 안 센다(서사에는 자유롭게 등장)」와 「개념 자체가 없다」** 두 갈래라는 것이 여기서 나왔다. 룰북 조사(`RULEBOOK-SURVEY.md` §3·§4)가 이미 같은 구분(`discretionary` vs `none`)을 권고하고 있었음을 확인해 함께 기록했다. AI에게 보내는 것도 「없다」가 아니라 「어떻게 다루는가」로 바뀌었다.

**Q4. 안 세는 룰북에서 플레이어가 「기사의 증표를 꺼낸다」고 선언하면?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 그냥 서사로 흘러간다 | 세는 목록이 없으니 「없는 것을 쓴다」는 판단이 성립하지 않는다 | ✓ |
| 한 번 물어보고 진행한다 | 판이 기울지 않게 하지만 물건마다 장면이 끊긴다 | |
| 룰북이 그것도 고르게 한다 | 가장 유연하지만 룰북이 답할 항목이 하나 늘어난다 | |

## 굴리지 않는 것이 정상으로 보이나

**논의 시작 전 코드에서 확인한 것:** 분류기가 고를 무브가 없으면 화면에 「인식된 행동이 없어요. 다른 문장으로 다시 말해 보세요 — [다시 쓰기]」가 뜨고 턴이 죽는다. 즉 「굴릴 필요 없음」이 「못 알아들었음」으로 표시되고, 판정 없이 이야기가 이어지는 길이 없다.

**Q1. 굴릴 필요가 없는 행동을 선언했을 때?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 그냥 진행된다 | 판정 없이 진행자가 서술한다. 실제 출간작들의 방식 | ✓ |
| 사람에게 한 번 물어본다 | 판이 기우는 것을 감시할 수 있지만 버튼이 하나 더 는다 | |
| 지금처럼 다시 쓰라고 한다 | 고칠 것이 없지만 RULE-15가 지켜지지 않는다 | |

**Q2. 「굴릴 필요 없음」과 「못 알아들음」을 어떻게 가릅니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 분류기가 셋으로 답한다 | 판정 있음 / 판정 불필요 / 모르겠음. 모르겠음만 다시 쓰기로 | ✓ |
| 모르겠을 때도 확인받고 진행 | 막다른 길이 없어지지만 오해한 문장도 이야기가 된다 | |
| 구분 없이 전부 진행 | 가장 매끄럽지만 세션1에서 본 종류의 사고가 재발한다 | |

**Q3. 판정 목록이 아예 없는 룰북에서는 주사위가 어떻게 굴러갑니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 룰북이 둘 중 고른다 | 「주사위를 안 굴리는 게임」과 「굴리되 목록이 아니라 그 자리에서 정하는 게임」 | ✓ |
| 항상 AI가 제안하고 사람이 확인 | 규칙이 하나라 단순하지만 주사위 없는 룰북이 계속 제안을 받는다 | |
| 목록이 없으면 판정도 없다 | 가장 단순하지만 D&D 계열 다수를 표현하지 못한다 | |

**메모:** 「안 쓴다」가 두 갈래로 갈린 것과 같은 구조가 판정 쪽에서도 반복된다는 점을 짚고 제시했다.

## 이번에 실제로 어디까지 만드나

**Q1. 표현 형태를 몇 가지까지 실제로 만드십니까?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 네 가지 | 숫자+상한 · 세그먼트 원 · 태그 목록 · 없음 (권장안이었음) | |
| 여섯 가지 전부 | 그릇이 진짜로 넓은지 이번에 끝까지 증명한다 | ✓ |
| 세 가지 | 가장 빨리 끝나지만 「룰북이 모양을 고른다」가 사실상 성립하지 않는다 | |

**같이 확정한 원칙:** 이번에 안 만든 형태는 룰북이 선언해도 등록에서 거부한다 — 선언은 받아놓고 화면에 안 나오는 상태를 만들지 않는다.

**Q2. 그릇을 증명할 세 번째 룰북을 이번에 넣을까요?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 넣는다 — 반대쪽 끝으로 | 플랫폼 코드를 안 고치고 들어가는지가 진짜 증거 | ✓ |
| 시험 데이터로만 확인한다 | 가볍지만 「우리가 상상한 모양에만 맞춘」 위험이 남는다 | |
| 이번엔 그릇만 | 단계가 가벼워지지만 그릇이 맞았는지는 다음에야 안다 | |

**메모:** 세 번째 룰북은 저작권이 깨끗한 공개 자료(SRD)여야 하고 자체 창작 미니 룰북은 D-18이 이미 배제했다는 제약을 먼저 알린 뒤 선택받았다. 후보 존재 여부는 조사 단계가 답한다.

**Q3. 등록할 때 무엇을 「걸린다」고 볼까요?**

| 선택지 | 설명 | 선택 |
|---|---|---|
| 가려짐과 구멍만 잡는다 | 겹침은 정상. 기존 두 룰북이 그대로 통과한다 | ✓ |
| 겹침도 전부 잡는다 | 룰북만 보고 결과를 알 수 있지만 기존 두 룰북을 다시 써야 한다 | |
| 겹침은 경고만 | 중간이지만 경고가 쌓이면 아무도 안 읽는다 | |

**메모:** 성공 기준 5의 「겹치거나」를 글자 그대로 구현하면 기존 두 룰북이 등록 거부된다는 것을 코드로 확인해 먼저 보고한 뒤 선택받았다.
