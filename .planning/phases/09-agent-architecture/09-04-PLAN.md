시나리오 원문을 받지 않는다. 에이전트 역할이 둘에서 다섯으로 늘었다.

다른 역할의 값을 물려받은 것이라면 터미널의 표준오류에 그 사실을 알리는 줄이 함께

**1) 명령줄로 한 턴**
```
uv run gptrpg turn --db .gptrpg/uat9.db --session uat9 --player bram --text "우물 안을 들여다본다"
```

② 서사가 한국어 문장으로 자연스럽게 나온다 ③ 서사 안에 진행자 지시문 문구나 시나리오
설정 원문("정체"·"원하는 것"에 해당하는 설명)이 **안 나온다** ④ 표준출력 어디에도 판단
실패 문구가 없다. 실패가 있었다면 표준오류에만 있어야 한다.

**2) 사건 기록 확인**
```
uv run gptrpg replay --db .gptrpg/uat9.db --session uat9
```
`ai_invoked` 계열 기록에 `situation_judge`·`scene_entity_judge`·`clock_judge` 세 역할이
전부 나타나는지, 그리고 시계 칸 값이 화면에 어떻게 찍히는지 본다.

**3) 시계가 폭주하지 않는지 — 연속 다섯 턴**
같은 세션에 서로 다른 문장으로 `turn`을 다섯 번 더 돌린다. 그 뒤 `replay`로 시계 칸을
본다. **판단 기준: 다섯 턴 만에 시계가 마지막 칸(4/4)에 닿아 있으면 판단이 너무
헐겁다는 신호다.** 그런 경우 이 체크포인트를 승인하지 말고 아래 "이슈" 쪽으로 알려
달라 — 프롬프트의 판단 기준을 조이는 후속 작업이 필요하다.

**4) 브라우저 경로**
```
GPTRPG_DB=.gptrpg/uat9.db uv run uvicorn gptrpg.web.app:app --host 0.0.0.0 --port 8000
```
브라우저에서 캐릭터를 고르고 한 턴을 끝까지 돌린다. 확인할 것 — ① 확인 버튼을 누른
뒤 서사가 나오기까지의 체감 지연이 이전보다 눈에 띄게 길어지지 않았다(판단 셋이
동시에 돌기 때문이다) ② 서사에 지시문 유출이 없다 ③ 시계 머리띠 값이 이상하게
튀지 않는다.

**5) 판단이 죽었을 때**
`clock_judge` 역할만 존재하지 않는 모델 이름으로 바꿔 두고 한 턴을 더 돌린다:
```
uv run gptrpg agents set --role clock_judge --provider <이름> --model no-such-model-xyz
```
확인할 것 — 턴이 **정상적으로 끝나고** 서사가 그대로 나오며, 화면에는 아무 이상이
없고 표준오류에만 실패 줄이 뜬다(D-05). 확인 후 원래 모델로 되돌린다.
