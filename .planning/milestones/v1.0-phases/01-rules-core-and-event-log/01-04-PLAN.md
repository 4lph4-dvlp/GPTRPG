<objective>
트레이서가 뚫어 놓은 판정 경로를 **2d6 등급식 판정 방식 하나가 실제로 끝까지 도는 수준**으로 넓힌다. 등급 경계를 고정하고, 수정치가 어디서 왔는지를 기록에 남기고, 재굴림이 일어났을 때 앞선 눈을 지우지 않고 이어 붙이게 한다.

그리고 이 계획의 절반은 **경계값 테스트**다. 등급이 갈리는 지점 바로 양쪽, 수정치가 하나도 없는 경우, 같은 눈이 여러 번 나오는 경우, 합계가 2~12를 벗어나는 경우가 전부 단언된다.

Purpose: 성공 조건 2번("주사위를 굴리고 판정 결과가 나오기까지 AI가 끼어드는 지점이 코드 어디에도 없다")은 판정이 실제로 한 번은 돌아야 증명된다. 그리고 Phase 2가 "여기에 두 번째 판정 방식을 넣어 봤더니 플랫폼 코드를 고쳐야 했나"를 재는 진짜 시험장이 되려면 첫 번째가 실물로 있어야 한다.

Output: 완성된 2d6 판정 방식 + 재굴림 + 경계값을 못박은 테스트 두 벌.

**범위선:** 수정치 네 유형(숫자 가감 / 주사위 추가·제거 / 목표값 변경 / 재굴림)이 전부 표현되는 것은 로드맵이 Phase 2에 배정한 요구사항(RIG-08)이다. 이 계획은 그중 숫자 가감을 계산에 반영하고, 나머지 세 유형이 들어올 자리(수정치의 `type` 칸)를 기록 수준에서 열어 둔다. 계산에 반영하지 못하는 유형이 들어오면 조용히 무시하지 않고 분명한 예외로 실패한다.
</objective>
