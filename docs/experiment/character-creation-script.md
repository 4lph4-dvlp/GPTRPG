# 캐릭터 만들기 구두 안내 대본

**이것은 설명 문서가 아니라 진행자가 손에 들고 소리 내어 읽는 대본이다.**

- **읽을 문장**은 큰따옴표 없이 그대로 옮겨 적혀 있다. 진행자가 참가자에게 소리 내어 읽는다.
- *(괄호 지시문)*은 진행자만 본다. 참가자에게 읽지 않는다.

대상은 TRPG를 한 번도 안 해 본 사람 두 명이다. 화면은 없다 — 캐릭터 만들기 화면은 M0에서 만들지 않는다(EXP-04). 이 대본과 종이(또는 메모장) 한 장만으로 진행한다.

**이 대본이 다루는 능력치 이름·무브 이름·판정 방식은 이 실험에 쓰는 룰북(던전월드 계열) 하나의 내용이다 — 이 시스템의 보편 규칙이 아니다.** 다른 룰북을 쓰면 이 대본은 다시 써야 한다.

**예산: 총 30분.** 아래 각 단계 옆에 분 단위 소요 시간이 적혀 있고, 합계는 30분을 넘지 않는다.

**한 명씩 vs 동시에 (진행자 판단):** 진행자가 참가자 두 명을 동시에 챙기기 벅차면 한 명씩 순서대로 진행한다. 두 참가자가 서로의 선택에 자극받아 더 몰입한다고 판단되면 나란히 앉혀 동시에 진행해도 된다 — 어느 쪽이든 참가자 한 명당 위 시간 예산은 그대로 지킨다.

---

## 단계 구성

design-plan.md §6.2의 "순서를 바꾼다" 원칙을 따른다 — 재미있는 것(누구인가)을 먼저, 기계적인 것(숫자)을 뒤로 배치한다. 각 단계 제목 옆 괄호에 이 단계가 design-plan.md §6.1의 창작 동작 일곱 가지(①~⑦) 중 무엇에 해당하는지 표시한다.

### 1단계 — 누구인가 (① 목록에서 하나 고르기) — 5분

*(참가자에게 이렇게 묻는다.)*

> 당신은 위험을 어떻게 마주합니까?
>
> ▸ 몸으로 먼저 막아선다
> ▸ 그림자 속에서 조용히, 들키지 않게 움직인다
> ▸ 무슨 일이 벌어지고 있는지 먼저 알아내려 한다
> ▸ 말로 상대의 마음을 움직이려 한다

*(참가자가 고르면, 그 선택이 어떤 사람인지 알려준다.)*

- **"몸으로 먼저 막아선다"를 골랐다면:** 당신은 위험 앞에서 물러서지 않는 사람입니다. 힘으로 부딪히는 쪽입니다.
- **"그림자 속에서 조용히 움직인다"를 골랐다면:** 당신은 소리 없이 다가가고, 자물쇠나 함정 같은 것을 다루는 데 능한 사람입니다.
- **"무슨 일이 벌어지고 있는지 먼저 알아내려 한다"를 골랐다면:** 당신은 지식과 관찰로 상황을 꿰뚫어 보려는 사람입니다.
- **"말로 상대의 마음을 움직이려 한다"를 골랐다면:** 당신은 설득과 담판으로 길을 여는 사람입니다.

*(이어서 이렇게 묻는다 — ⑥ 자유롭게 쓰기, 05-01 시나리오 세계 안에서 "왜 여기 있는가"를 받는다.)*

> 당신은 왜 지금 우물 마을(오늘 이야기의 무대, "우물 아래의 것"이 시작되는 곳)에 있습니까? 한 문장으로 말해 주세요.

*(참가자가 말한 문장을 그대로 받아 적는다. 이 문장이 나중에 캐릭터의 한 줄 소개가 된다 — 예: "우물 마을 순찰대에 뒤늦게 합류한 떠돌이 검객", "밤그림자처럼 마을에 흘러든 나그네".)*

### 2단계 — 무엇을 잘하나 (④ 정해진 숫자를 자리에 배치) — 10분

*(이 룰북은 ② 목록에서 여러 개 고르기, ③ 숫자를 나눠 담기, ⑤ 주사위 굴려 채우기를 쓰지 않는다 — 대신 정해진 숫자 묶음을 여섯 자리에 배치하는 방식(④)과 자유 서술(⑥)로 능력을 표현한다.)*

이제 여섯 가지 능력치에 정해진 숫자 묶음 `+2, +1, +1, 0, 0, -1`을 나눠 놓습니다. 이 숫자들이 무엇을 뜻하는지 먼저 알려드릴게요.

- **STR(힘)이 높으면:** 적과 직접 무기를 맞대고 싸울 때(근접전) 유리합니다.
- **DEX(민첩)이 높으면:** 거리를 두고 활이나 투척 무기로 공격할 때, 그리고 자물쇠를 따거나 함정을 해체할 때 유리합니다.
- **CON(체질)이 높으면:** 누군가나 무언가를 위험으로부터 몸으로 막아설 때 유리하고, 체력도 더 튼튼해집니다.
- **INT(지능)이 높으면:** 세계에 대한 지식을 캐물어 알아낼 때 유리합니다.
- **WIS(지혜)가 높으면:** 주의 깊게 주변을 살피거나 흔적을 추적할 때 유리합니다.
- **CHA(매력)이 높으면:** 레버리지를 걸고 상대에게 무언가를 요구하며 담판을 지을 때 유리합니다.

*(1단계에서 고른 사람됨에 맞는 추천 배치를 먼저 제시하고, 참가자가 원하면 바꾸게 한다.)*

| 1단계 선택 | 추천 배치 (STR/DEX/CON/INT/WIS/CHA) |
|---|---|
| 몸으로 먼저 막아선다 | +2 / 0 / +1 / -1 / 0 / +1 |
| 그림자 속에서 조용히 움직인다 | 0 / +2 / -1 / 0 / +1 / +1 |
| 무슨 일이 벌어지는지 먼저 알아낸다 | -1 / 0 / 0 / +2 / +1 / +1 |
| 말로 상대의 마음을 움직인다 | 0 / +1 / -1 / +1 / 0 / +2 |

*(참가자가 표를 그대로 받아들이면 그 값을 쓰고, 자리를 바꾸고 싶다고 하면 여섯 자리 사이에서 숫자만 옮기게 한다 — 숫자 묶음 자체(`+2, +1, +1, 0, 0, -1`)는 바뀌지 않는다.)*

### 3단계 — 자동으로 정해지는 것 (⑦ 자동 계산) — 3분

*(진행자가 대신 계산해 알려준다. 참가자는 계산하지 않는다.)*

체력은 `16 + CON 값 × 2`로 정해집니다. *(예: CON이 +1이면 체력 18, CON이 -1이면 체력 14.)* 방금 계산한 값을 알려주세요.

방어구를 가질지는 1단계에서 고른 사람됨에 따라 진행자가 제안합니다 — "몸으로 먼저 막아선다"를 고른 사람에게는 방어구를 제안하고, 그 외에는 제안하지 않습니다. 참가자가 원하면 방어구 없이 시작해도 됩니다.

### 4단계 — 이름·모습 (⑥ 자유롭게 쓰기) — 5분

> 이 사람의 이름은 무엇입니까? 겉모습을 한 문장으로 말해주면 제가 받아 적을게요.

*(참가자가 말한 그대로 받아 적는다.)*

### 5단계 — 완성 순간 (design-plan.md §6.2 장치 6) — 2분

*(진행자가 완성된 캐릭터를 소리 내어 되읽어 준다.)*

> [이름] — [1단계에서 받은 한 줄 소개]. 여기 당신의 캐릭터가 완성되었습니다.

### 6단계 — 애착 질문 (MEAS-06) — 3분

**캐릭터가 완성된 직후, 진행자가 다음 문구를 정확히 그대로 한 번 묻는다.**

> 당신 캐릭터 어떤 사람이에요?

*(참가자가 말한 문장을 그대로 받아 적는다. 유도하지 않는다 — "멋진 캐릭터죠?" 같은 되묻기 금지. 되묻지 않는다. 요약하거나 윤색하지 않는다 — 참가자가 말한 문장을 그대로 옮겨 적는다. 대답의 길이와 막힘 자체가 애착 형성 여부의 신호다. 답을 적을 자리는 관찰 기록 양식(05-03, `docs/experiment/observation-log-template.md`)에 있다.)*

**소요 시간 합계: 5 + 10 + 3 + 5 + 2 + 3 = 28분** (30분 예산 안).

## 시간이 모자랄 때

기계적 단계(2단계 능력치 배치, 3단계 체력 계산·방어구)는 진행자가 추천값으로 그대로 넘긴다. **1단계(사람됨을 정하는 단계)는 절대 건너뛰지 않는다** — 그 단계를 건너뛴 캐릭터에는 애착이 안 생기고, 그러면 MEAS-06으로 재려던 것 자체가 사라진다.

## 필드 대응표

**손대는 칸은 `seon`·`hodu` 두 키뿐이다. `bram`·`nari`는 어떤 이유로도 건드리지 않는다(D-49 — 브람·나리는 그대로 유지).** 아래 규격(능력치 배열·체력 공식)도 새로 만드는 두 캐릭터(`seon`/`hodu`)에만 적용된다.

파일: `src/gptrpg/web/characters_data.py`

| 대본이 받은 값 | 코드의 칸 |
|---|---|
| 이름 | `PLAYER_CHARACTERS["seon"\|"hodu"]`의 `Entity.display_name` |
| 한 줄 소개(1단계 "왜 여기 있는가") | `CHARACTER_ARCHETYPES["seon"\|"hodu"]` |
| 체력 (3단계 계산값) | `StatEntry(name="체력", current=N, max=N, depleted_effect_ref="dungeonworld_like.hp_depleted")` |
| 능력치 여섯 (2단계 배치값) | `StatEntry(name="STR"\|"DEX"\|"CON"\|"INT"\|"WIS"\|"CHA", current=N)` |
| 방어구 (선택, 3단계) | `StatEntry(name="방어구", current=N)` |

**바꾸지 않는 것:** `entity_id`(`player.seon`/`player.hodu`)와 딕셔너리 키(`seon`/`hodu`) — 웹 라우트와 쿠키가 이 식별자를 쓴다.

편집 후 `uv run pytest tests/test_web_characters.py -q`를 돌려 규격을 벗어나지 않았는지 확인하라.
